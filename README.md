# Quiz-databas

Ett Python-skript som skapar och fyller en SQLite-databas ('quizdata.db') med frågor och svarsalternativ. DB browser kan användas som kontroll vilket görs regelbundet under arbetsgången.

## Så här kör du projektet:
1. Se till att du har Python 3.
2. Kör skriptet: 'python create_db.py'

## Nästa steg i projektet
- Att implementera lastrowid för att undvika dubletter
- Lägga till mer data
- Göra quizzet körbart
